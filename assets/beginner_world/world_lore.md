# 澄源县世界背景

> L2 人类可读世界资产。当前 Runtime 不自动加载；未来可作为 RAG 和场景生成的背景来源。

## 时代与县城

故事发生在架空王朝晟朝末年。社会生活大致参考明末，但不绑定真实历史人物、战役或年号。朝廷与县衙仍能维持日常秩序，然而局部旱涝、财政吃紧、商路中断与流民增加，已让所有人感到局势正在变坏。

澄源县位于区域商路节点，县城、农地、丘陵与山林相接。当前 Scene 开放县城与东门外山林；村庄、官道和更大的州府仍是背景，尚未开放为可达地点。

## 社会网络

县衙、乡绅地主、商人与商会、普通百姓、灰色势力、流民与外来者共同构成利益网络。它们不是固定阵营；人物行为应由身份、当前状态、关系、利益、知识与性格共同决定。

## 初始异常

- 城外部分村庄收成低于往年，农户开始提前出售存粮。
- 一支运粮商队迟迟没有返回。
- 北方流民增加，东门检查更严格。
- 县衙准备核对粮册与税册，各方因此不安。
- 官道附近有山匪传闻，但来源尚未证实。

这些异常预期形成因果链，例如：商队延误 -> 粮食供给下降 -> 粮价上涨 -> 偷盗增加 -> 巡逻加强 -> 地下交易活跃。它们当前只是 L2 模板和背景，不是已经发生的 L3 Runtime 事实。

## 场景原则

地点不是任务关卡。县城应允许日常、生产、交易、传闻与冲突并存；山林秩序较弱，但仍遵循现实规则，超凡力量保持关闭。任何剧情性结果都必须经过 Resolver，不能因背景描述或 Narrator 文本直接成立。
