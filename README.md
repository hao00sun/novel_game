# Novel World 📖🎮

> Turn novels into interactive worlds.
> 将小说变成一个可以进入、探索和改变的世界。

## 中文

**Novel World** 是一个开源的 AI 沉浸式小说项目。

项目希望将普通小说解析为一个可交互的虚拟世界，让玩家不再只是阅读故事，而是能够：

* 扮演小说中的角色或创建自己的角色
* 与小说人物进行自然语言互动
* 探索小说中的地点和事件
* 在保留原著世界观的基础上改变剧情
* 让 AI 根据玩家行为实时生成新的故事发展

### 目标流程

```text
小说 / Novel
      ↓
人物 · 地点 · 事件 · 世界观
      ↓
Knowledge Base / RAG
      ↓
World State + Character Agents
      ↓
LLM Story Engine
      ↓
玩家选择与自由行动
      ↓
新的剧情世界
```

### 计划功能

* [ ] 小说 TXT / EPUB / PDF 导入
* [ ] 自动提取人物、地点和事件
* [ ] 世界观知识库
* [ ] 角色 Agent
* [ ] 长期剧情记忆
* [ ] 世界状态管理
* [ ] 原著剧情与分支剧情
* [ ] Web 游戏界面
* [ ] AI 场景图片
* [ ] TTS 角色语音

项目目前处于早期开发阶段。

## English

**Novel World** is an open-source AI project for turning novels into interactive worlds.

Instead of simply reading a story, players will be able to:

* Play as an existing character or create a new one
* Talk naturally with characters
* Explore locations and events from the novel
* Make decisions that affect the original storyline
* Generate new story branches dynamically with AI

### Core Pipeline

```text
Novel
  ↓
Characters · Locations · Events · Lore
  ↓
Knowledge Base / RAG
  ↓
World State + Character Agents
  ↓
LLM Story Engine
  ↓
Player Actions
  ↓
Dynamic Story World
```

### Roadmap

* [ ] TXT / EPUB / PDF import
* [ ] Character, location and event extraction
* [ ] Lore / world knowledge base
* [ ] Character agents
* [ ] Long-term story memory
* [ ] World-state management
* [ ] Canon and alternative storylines
* [ ] Web-based game interface
* [ ] AI-generated scene images
* [ ] Character TTS

This project is currently in an early stage of development.
